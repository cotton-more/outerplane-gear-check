# Outerplane Gear Check

Личная страница для быстрой чистки инвентаря в Outerplane. Открываешь её рядом с игрой (или на телефоне),
в несколько нажатий вбиваешь предмет и получаешь вердикт — **Оставить / Временно / Фоддер / Спорно / Разобрать** —
и список персонажей, которым он подходит. Вторая вкладка — во что одевать конкретного персонажа.

Данные — курированные билды [outerpedia](https://github.com/Sevih/outerpedia) (`data/curated/gear-reco.json`)
и игровые таблицы снаряжения оттуда же. Сверено с живым сайтом: все 265 билдов 95 персонажей совпадают.

## Файлы

| Файл | Что это |
|---|---|
| `docs/` | PWA-сайт для GitHub Pages: `index.html`, иконки `img/`, `manifest.webmanifest`, `sw.js` (офлайн и обновления) |
| `PUBLISH.md` | как выложить `docs/` на GitHub Pages и обновлять сайт |
| `update.py` | скрипт обновления данных (Python 3.9+, без внешних пакетов) |
| `template.html` | исходник страницы: разметка, стили, логика оценки (блок `CFG` — все пороги) |
| `outerplane-gear.html` | одиночная страница — один файл, иконки встроены, работает офлайн (не в git) |
| `build/artifact.html` | та же страница без `<html>`-обёртки — для Claude Artifact (не в git) |

Кэш скачанных иконок лежит вне проекта — в `~/Library/Caches/outerplane-gear` (macOS) или `~/.cache/outerplane-gear`
(Linux). Его можно удалить в любой момент: следующий запуск скачает иконки заново за несколько секунд.

## Приложение на телефоне (PWA)

Открой сайт на GitHub Pages в Chrome и выбери в меню ⋮ «Установить приложение» (или нажми кнопку внизу страницы).
Появится иконка на рабочем столе: приложение открывается без адресной строки, работает офлайн и подходит для
разделённого экрана с игрой. Когда данные обновятся, при следующем открытии появится плашка
«Вышли новые данные — Обновить». Ростер хранится отдельно для каждого адреса: перенеси его через «экспорт / импорт».

## Как пользоваться

**Оценка предмета**

1. Слот (`1`–`6` на клавиатуре) и грейд (`L` — Legendary, `E` — Epic). Всё, что ниже 6★ Epic, — сразу в разбор
   (единственное исключение из билдов — Bloody Edge 5★ у Eliza, о нём напомнит слот оружия).
2. **Броня** — сет. Грейд и сет видны в названии: `Etheric Gloves of Speed` = Legendary, Speed Set; `Steel …` = Epic.
   **Legendary оружие/аксессуар** — найди по названию или пассивке, выбери main stat.
   **Epic оружие/аксессуар** (Steel Sword / Steel Necklace) — пассивки у них нет, поэтому сразу выбираешь main stat.
3. Сабстаты (до 4). Выбранный стат сразу получает 1 жёлтый сегмент; если выпало больше — нажми 2, 3 или 4.
   Снять стат — нажать на него ещё раз.
4. Читай вердикт и жми «Следующий предмет» (`Esc`). На телефоне вердикт закреплён внизу экрана вместе с кнопкой «Далее».

Удобно открывать в режиме разделения экрана: игра сверху, страница снизу. Если браузер открыл файл в режиме
«Версия для ПК» (так бывает при открытии из «Файлов»), страница сама это распознает и переключится на мобильную
раскладку; надёжнее всё же выключить этот режим в меню Chrome ⋮.

**Персонажи** — поиск по имени. Одноимённые различаются префиксом: *Stella* / *Demiurge Stella*,
*Delta* / *Demiurge Delta* / *Heatwave Cop Delta*, *Snow* / *Core Fusion Snow*… Все билды outerpedia идут вкладками:
сеты (с альтернативами), оружие и аксессуар с main stat, приоритет сабстатов с подсказкой flat/%, талисманы, заметка.

**Ростер** — отметь звёздочкой своих персонажей, и оценка будет учитывать только их («только мои персонажи»).
Предмет, хороший для кого-то не из ростера, получит «Спорно», а не «Разобрать». Ростер хранится в браузере
(localStorage); «экспорт / импорт» переносит его кодом. Ссылка `outerplane-gear.html#demiurge-stella`
сразу открывает персонажа.

## Как считается вердикт

**Броня.** «Полезный» сабстат — тот, что стоит в 1–3 ступени приоритета билда (4-я ступень — за ½, SPD — на любой
ступени). Берётся лучший билд среди персонажей, которые носят этот сет.

- Оставить: 3+ полезных, или 2 полезных, если среди них SPD с 2+ жёлтыми сегментами. Правило одинаковое для Legendary и Epic.
- Иначе — разобрать. Для Breakthrough и реролла Transistone (Total) сабстаты не важны, поэтому «фоддер» не зависит
  от сабстатов. Если копишь Legendary броню для T4, включи это в настройках: такие предметы станут «Фоддер»
  (держать стоит не больше 4 на сет и слот).
- Сеты, которых нет ни в одном билде outerpedia (Critical Hit, Resilience, Fortification, Mitigation, Lifesteal,
  Bursting, Pulverization, Weakness), — «скорее разбирай» с объяснением. Список пересчитывается при обновлении данных.

**Flat ATK/DEF/HP.** %-сабстат умножает только собственную базу персонажа (уровень + эволюции + flat-бонусы Quirks),
flat прибавляет фиксированное число. Поэтому ценность flat считается для каждого персонажа отдельно, тем же расчётом,
что на outerpedia. В среднем flat ATK ≈ 0.9 от ATK%, flat DEF ≈ 1.0 от DEF%, flat HP ≈ 0.6 от HP%.
Слабый flat засчитывается за ½ или не считается. Уровень (100/120) и Quirks — в «Настройках оценки».

**Оружие и аксессуары.**

- Legendary с пассивкой из билдов и нужным main stat → оставить (сабстаты правятся Precise Craft / Transistone).
- С той же пассивкой, но не тем main stat → фоддер для Breakthrough (main stat не перебрасывается — так советует гайд outerpedia).
- **Временно**: предмет без нужной пассивки (любой Epic или Legendary не из билдов), у которого main stat — тот,
  что персонажи просят в этом слоте, **и хороший ролл**: 3 полезных сабстата или 2 полезных с 5+ жёлтыми сегментами
  на них (у предмета с 4 сабстатами — 3 полезных). Иначе — «Разбирай — слабый ролл». Main ATK% на оружии просят
  66 персонажей, SPD на аксессуаре — 58, но из случайных Epic проходит примерно каждый пятый-седьмой.
  Держи 1–2 лучших на каждый нужный main stat.
- Этап «Эндгейм» в настройках отключает временные замены: тогда в разбор идёт всё, что не рекомендовано.

**Ролл.** При отмеченных сабстатах вердикт показывает строку «Ролл: полезных N из M, жёлтых сегментов на них X из 3·M».
Если жёлтых на полезных статах 60%+ от максимума, появляется плашка «Стоит прокачать»: такой предмет выгодно
вкладывать в Reforge.

Процент в подсказке у персонажа — взвешенная оценка по ступеням приоритета, используется для сортировки.
Все пороги — в блоке `CFG` в `template.html`; после правки запусти `update.py`, чтобы пересобрать страницу.

## Обновление данных

```bash
python3 update.py              # одиночная страница outerplane-gear.html
python3 update.py --pwa docs   # PWA-сайт в docs/
```

Сайт обновляется вручную, с этого компьютера: собрать `docs/`, проверить локально
(`python3 -m http.server -d docs 8000`), закоммитить и запушить — GitHub Pages раздаёт `docs/` из ветки `main`.
Подробности и разовая настройка — в [`PUBLISH.md`](PUBLISH.md). Если данные не менялись, сборка байт в байт та же:
лишних коммитов и ложных «обновлений» на телефоне не будет.

Скрипт берёт последний коммит outerpedia с GitHub, пересобирает страницу и печатает, что изменилось:
новые и пропавшие персонажи, обновлённые билды, переименования, новые предметы и сеты.
Новые персонажи помечаются на странице значком NEW. Ростер и настройки в браузере сохраняются.
Если outerpedia поменяет формат данных и какие-то рекомендации не сопоставятся, скрипт напишет об этом отдельно.

Флаги:

- `--source ~/path/to/outerpedia` — взять данные из локального клона вместо скачивания;
- `--ref <sha>` — зафиксировать конкретный коммит;
- `--no-embed` — не встраивать иконки (файл ~0.3 МБ вместо ~2 МБ, но иконкам нужен интернет);
- `--refresh-images` — перекачать иконки, не глядя в кэш;
- `--out путь.html` — писать страницу в другое место (вариант для публикации ляжет рядом как `путь.artifact.html`);
- `--dump-json data.json` — дополнительно сохранить датасет в JSON;
- `--pwa DIR` — собрать PWA-сайт в папку (вместо одиночной страницы).

Регулярное обновление можно повесить на cron, например раз в неделю по понедельникам
(собрать, и если что-то изменилось — запушить на Pages):

```cron
0 10 * * 1 cd ~/Projects/outerplane-gear && /usr/bin/python3 update.py --pwa docs >> update.log 2>&1 && git add -A && ! git diff --cached --quiet && git commit -qm "Обновление данных outerpedia" && git push -q
```

## Ограничения

- Рекомендации outerpedia в основном PvE; сеты без билдов (Resilience, Mitigation…) могут иметь нишевое PvP-применение.
- Сколько копий нужно для T4 (обычно 4) и начальное число сабстатов у Epic (3) — со слов гайдов, в данных игры этого нет.
- Классовые версии Briareos/Gorgon в игре называются одинаково: класс видно по иконке на плитке и суффиксу пассивки.
- Эффект EFF/RES-сабстатов в данных игры не до конца ясен, поэтому они оцениваются только по приоритетам билдов.

Игровые данные и изображения принадлежат Major9 / VA Games; билды — работа авторов outerpedia.
Это личный инструмент, не связанный с издателем.
