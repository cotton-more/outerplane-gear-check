# Персонажи и код для гильдии

## Персонажи

Вторая вкладка (☰ → «Персонажи»): поиск по имени и все билды outerpedia — сеты с альтернативами, оружие и аксессуар
с main stat, приоритет сабстатов с подсказкой flat/%, талисманы, заметка. Звёздочка добавляет персонажа в ростер;
с «только мои персонажи» оценка учитывает только их. Ссылка `…/#demiurge-stella` сразу открывает персонажа.

Core Fusion заменяет героя: в игре после Core Fusion обычного героя больше нет, поэтому в ростере бывает кто-то
один. Отметишь Core Fusion Eternal — Eternal уйдёт из ростера (сообщение с «Вернуть»), а Eternal при Core Fusion
Eternal в ростере не добавится. Импорт кода экипировки добавляет в ростер всех, у кого есть вещи.

<img src="https://raw.githubusercontent.com/cotton-more/outerplane-gear-check/main/screenshots/ru/6-character.png" width="360" alt="Карточка персонажа с билдами outerpedia">

Ростер на другое устройство переносится кодом: «экспорт / импорт» на вкладке персонажей. Всё, что ты отмечаешь,
хранится только в твоём браузере — никуда не отправляется.

Что надето на персонажа в каждом билде — см. [Экипировка](Экипировка).

## Код вещи для гильдии

В подробностях вердикта есть код, например `OGC KXRM TPWA`. «Скопировать» — и вставь в чат игры (8–11 букв при
лимите 50 символов). Кто получил — ☰ → «Ввести код» и перепечатывает: в коде только буквы, регистр и пробелы не
важны, опечатку поймает контрольная буква. Оценка у каждого — по своему ростеру и настройкам.
