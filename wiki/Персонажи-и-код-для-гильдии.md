# Персонажи и код для гильдии

## Персонажи

Вторая вкладка (☰ → «Персонажи»): поиск по имени и все билды outerpedia — сеты с альтернативами, оружие и аксессуар
с main stat, приоритет сабстатов с подсказкой flat/%, талисманы, заметка. Звёздочка добавляет персонажа в ростер;
с «только мои персонажи» оценка учитывает только их. Ссылка `…/#demiurge-stella` сразу открывает персонажа.

В карточке персонажа стихия и класс — значками на портрете, подкласс и роль — текстом. Звёздочка — рядом с именем,
как в списке. «outerpedia ↗» внизу шапки открывает гайд по персонажу на outerpedia в новой вкладке.

Вещи бывают только у персонажей ростера: «Надеть» добавляет персонажа в ростер, импорт кода экипировки — всех, у
кого есть вещи. Снимешь звезду с персонажа, у которого есть вещи, — окно предупредит, что вещи уберутся из приложения;
после «Да, убрать» — сообщение с «Вернуть».

Core Fusion заменяет героя: в игре после Core Fusion обычного героя больше нет, поэтому в ростере никогда нет обоих.
Отметишь Core Fusion Eternal — окно: вещи Eternal перейдут к Core Fusion Eternal, а Eternal станет неактивным. Неактивный
Eternal стоит в списке сразу за Core Fusion Eternal с пометкой «заменён Core Fusion Eternal», и вердикт Eternal не
учитывает. Звезда на Eternal вернёт всё назад — тоже через окно. После «Да» — сообщение с «Вернуть». Подробнее —
[Экипировка](Экипировка#core-fusion).

Ростер на другое устройство переносится кодом: «экспорт / импорт» на вкладке персонажей. Всё, что ты отмечаешь,
хранится только в твоём браузере — никуда не отправляется.

Вещи персонажа и как из них собираются билды — см. [Экипировка](Экипировка).

## Код вещи для гильдии

В подробностях вердикта есть код, например `OGC KXRM TPWA`. «Скопировать» — и вставь в чат игры (8–11 букв при
лимите 50 символов). Кто получил — ☰ → «Ввести код» и перепечатывает: в коде только буквы, регистр и пробелы не
важны, опечатку поймает контрольная буква. Оценка у каждого — по своему ростеру и настройкам.
